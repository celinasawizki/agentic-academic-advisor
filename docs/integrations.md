# Integrations and their status

| System | Status in MVP | Adapter | What a real integration needs |
|---|---|---|---|
| Temple Degree Audit (sites.temple.edu/degreeaudit) | Not connected. Behind university authentication; no public API. | `adapters/degree_audit.py` — local PDF parser + `TempleDegreeAuditAdapter` stub | Authorized API or export (e.g. via a TUportal test environment). Never scrape or bypass auth. |
| Academic Bulletin | **Ingested.** All 435 undergraduate majors, minors and certificates (2026-2027) and 6,800+ courses, parsed into structured rules with source URL and retrieval time. ≈490 prose rules flagged `manual`. Earlier catalog years not available (archives excluded by robots.txt). | `app/ingest/bulletin.py`, `scripts/ingest_bulletin.py`, `adapters/catalog.py` | Advisor verification workflow to promote rules from "parsed" to "verified"; archived catalog years via an authorized export. |
| Course Search (Banner SSB) | **Snapshot.** 8,690 Spring 2027 sections captured once (with the project owner's approval) at 1 request/second. The app never calls Temple at runtime. | `scripts/import_sections.py`, `adapters/course_search.py` — `SnapshotCourseSearchAdapter`, `TempleBannerCourseSearchAdapter` stub | An authorized endpoint or data export for live seats and times. |
| TUportal | Mock only. Drafts saved to `integration_status`; nobody is registered. | `adapters/tuportal.py` — `TUportalAdapter` interface, `MockTUportalAdapter` | Test-environment credentials and API docs. Implement `getStudentProfile, getDegreeAudit, getAcademicHistory, getAvailableSections, getRegistrationRestrictions, createDraftSchedule, validateDraftSchedule, getDraftSchedule`. Registration stays a separate, explicitly authorized action. |
| Ambler, Rome, Japan campuses | Shown in onboarding as future; in-person sections at unsupported campuses are excluded by Course Discovery. | `rules.SUPPORTED_CAMPUSES` | Campus-specific section data and rules. |
| Anthropic Claude | Optional (`ANTHROPIC_API_KEY`). | `agents/llm.py` | Institutional data agreement before sending any student education records (`LLM_MAY_RECEIVE_STUDENT_RECORDS`). |

New or changed programs are picked up by re-running `python -m scripts.ingest_bulletin --refresh`; no code changes are needed. Parser limitations: prose rules ("one additional course at the Foundation Level…"), program-specific substitutions, and requirement tables whose structure varies from CourseLeaf conventions are flagged rather than interpreted. Separate lecture/lab/recitation sections are scheduled as components of one course; Temple does not mark which lab belongs to which lecture, so any lab section of the course is considered compatible.
